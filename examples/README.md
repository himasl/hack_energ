# Примеры

Каждый пример — отдельная папка:

| Файл | Что это |
| --- | --- |
| `input.txt` | описание процесса, как его напишет аналитик |
| `code.py` | код на API `DIAGRAM` (сгенерированный моделью или эталонный) |
| `output.bpmn` | результат, открывается в [demo.bpmn.io](https://demo.bpmn.io) |
| `output.png` | картинка схемы для README и презентации |

| Пример | Участники | Что показывает |
| --- | --- | --- |
| `01_repair_request` | Диспетчер, Мастер участка, Бригада | ветвление (XOR) и параллельные работы (AND) |
