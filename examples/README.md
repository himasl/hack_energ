# Примеры

Каждый пример — отдельная папка:

| Файл | Что это |
| --- | --- |
| `input.txt` | описание процесса, как его напишет аналитик |
| `code.py` | код на API `DIAGRAM` (сгенерированный моделью или эталонный) |
| `output.bpmn` | результат, открывается в [demo.bpmn.io](https://demo.bpmn.io) |
| `output.png` | картинка схемы для README и презентации |

| Пример | Участники | Что показывает |
| --- | --- | --- |
| [Ремонт оборудования подстанции](01_repair_request/) | диспетчер, мастер участка, бригада | условие, параллельные работы, документ и журнал |
| [Технологическое присоединение](02_tech_connection/) | заявитель, специалист по ТП, отдел развития, сетевая организация, инспектор | возврат на дозагрузку документов, параллельные мероприятия двух сторон |
| [Работы по наряду-допуску](03_permit_to_work/) | выдающий наряд, допускающий, производитель работ, диспетчер | шаги в тексте не по порядку, три параллельные операции, переоформление |
| [Плановое отключение потребителей](04_outage_approval/) | район сетей, ЦУС, РЭС, энергосбыт, бригада | отказ или согласование, уведомление нескольких групп |
| [Ликвидация аварии](05_emergency/) | SCADA, диспетчер, оперативная и ремонтная бригады | система как участник, выбор схемы восстановления, повтор при неудаче |
| [Передача показаний приборов учёта](06_meter_readings/) | абонент, личный кабинет, биллинг, контролёр | пассивный залог в тексте, условие по сроку, проверка подозрительных показаний |
| [Согласование инвестиционного проекта](07_invest_approval/) | инициатор, технический эксперт, экономист, юрист, комитет | пять участников, два возврата на доработку |
| [Инцидент в АИИС КУЭ](08_ascue_incident/) | мониторинг, энергосбыт, первая и вторая линии, подрядчик, метролог | два способа старта, эскалация, параллельно с выбором по причине |
| [Обеспечение ремонта материалами](09_repair_materials/) | мастер, кладовщик, снабжение, бухгалтерия | частичная выдача со склада, закупка |

Примеры 02–09 построены моделью `gpt-oss:120b` по описаниям из [проверочного набора](../bench/README.md);
`code.py` — ответ модели без правок, `output.bpmn` и `output.png` собраны из него.
Пересобрать схемы из кода, без запросов к модели:

```bash
for t in examples/*/; do python -m bpmn_gen --code $t/code.py -o $t/output.bpmn --png; done
```
